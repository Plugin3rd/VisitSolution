# سامانه ثبت مراجعات

نسخه اولیه سامانه وب با C# و ASP.NET Core MVC و SQL Server.

## فناوری‌ها
- .NET 10
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- رابط فارسی و RTL

## اجرا
1. در `appsettings.json` مقدار `ConnectionStrings:DefaultConnection` را متناسب با SQL Server تغییر دهید.
2. SDK دات‌نت 10 را نصب کنید.
3. در پوشه پروژه اجرا کنید:

```bash
dotnet restore
dotnet run
```

در اجرای اول، دیتابیس با `EnsureCreated` ساخته می‌شود و نقش‌ها و یک کاربر مدیر ایجاد می‌گردند.

## کاربر اولیه
نام کاربری و رمز عبور از بخش `SeedAdmin` در `appsettings.json` خوانده می‌شود.
قبل از استقرار، حتماً رمز پیش‌فرض را تغییر دهید.

## قابلیت‌های موجود در این مرحله
- ورود و خروج کاربران سامانه
- نقش‌های مدیر سامانه، اپراتور، مشاهده‌گر
- مدیریت اولیه اشخاص
- مدیریت واحدهای سازمانی
- ثبت ورود و خروج
- جلوگیری از ثبت ورود شخص غیرفعال
- جلوگیری از ورود شخص دارای بلک‌لیست فعال
- جلوگیری از داشتن دو مراجعه باز همزمان
- ثبت Audit اولیه
- RecordVersion برای کنترل همزمانی در موجودیت‌های اصلی
- رابط کاربری فارسی و RTL

## مرحله بعد
پیشنهاد می‌شود در مرحله بعد Migrationهای EF Core، مدیریت کامل کاربران و Permissionها، ویرایش/حذف رکوردها، جستجوی پیشرفته، گزارش‌ها و خروجی Excel/PDF اضافه شوند.

> نکته: در محیط ایجاد این بسته، SDK دات‌نت روی سرور موجود نبود؛ بنابراین اجرای `dotnet build` در همین محیط انجام نشد. ساختار پروژه و کدها آماده Restore/Build در محیط توسعه دارای .NET 10 SDK هستند.
